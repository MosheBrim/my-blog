# My Blog

Welcome to My Blog! This is a feature-rich blogging platform where users can explore posts, add comments, and enjoy an engaging blogging experience. The platform also includes an admin system for managing posts, comments, and users, providing full control over the blog's content and community interactions.

## Live Demo
Check out the live demo on Vercel: [My Blog Live Demo](https://my-blog-101.vercel.app/)

## Features
- **Explore Posts:** View and read blog posts published by the community.
- **Comment System:** Add comments to posts and engage in discussions.
- **Admin Panel:** Manage posts, comments, and users from a dedicated admin interface.
- **Responsive Design:** Fully responsive and mobile-friendly interface.

## Technologies Used
- **React:** JavaScript library for building user interfaces.
- **CSS:** Used for styling the application.
- **Spring Boot:** Backend framework for building the server-side logic.
- **SQL Server:** Database management system to store and retrieve data.
- **Vercel:** Deployment platform for hosting the application.

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/MosheBrim/my-blog.git
   ```
2. Navigate to the project directory:
   ```bash
   cd My-Blog
   ```
3. Install client dependencies:
   ```bash
   cd client
   npm install
   ```
4. Start the client application:
   ```bash
   npm run dev
   ```
5. Navigate to the server directory and install dependencies:
   ```bash
   cd ../server
   mvn install
   ```
6. Run the Spring Boot server:
   ```bash
   mvn spring-boot:run
   ```

## How to Use
1. Open the application in your web browser using the live demo link or run it locally.
2. Explore the blog posts and add comments to any post.
3. If you have admin access, log in to manage posts, comments, and users.
4. Enjoy a seamless blogging experience!
